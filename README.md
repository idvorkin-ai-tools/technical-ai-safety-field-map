# Technical AI Safety — field map

A field map of [BlueDot Impact's Technical AI Safety course](https://bluedot.org/courses/technical-ai-safety): six units, twenty-seven chapters, one page per chapter. Each page explains the chapter in its own words, pins the course page at the top, links every assigned reading, and writes the exercises out (code ones flagged) so they can be done without the login.
